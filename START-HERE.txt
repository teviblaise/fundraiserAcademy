FUNDRAISER ACADEMY — LAPTOP PREVIEW

1. Install the current Node.js 24 LTS release from https://nodejs.org.
2. Extract the ZIP, then open a terminal in the fundraiserAcademy folder.
3. Run: npm ci
4. Run: npm start
5. Open http://localhost:3000 in your browser.

Keep the terminal open while using the website. Press Ctrl+C to stop it.
On Windows, these commands work in PowerShell or the VS Code terminal.
Use npm start rather than the VS Code Live Server extension: this website
includes a Node.js backend for registration, trading, and certificates.

Register a new account to try the trading dashboard. Cloud-instance users
and secrets are excluded from this export. Your laptop creates its own
private data folder. Email and background push need additional configuration;
in-page popup notifications work without provider credentials.

See README.md for features and DEPLOYMENT.md for later live hosting.

After passing the assessment, open Trader agreement. Signing is compulsory
before sponsorship review. The agreement stays pending until the company
provides its contract. No contract terms are included in this preview.
